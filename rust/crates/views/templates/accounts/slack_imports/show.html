Slack import

Move this workspace from Slack Pro to Smartfire: create an internal Slack app, connect it, dry-run the migration, then import. Full guide in docs/slack-import.md.

1. Create the Slack app

Create an internal app from this manifest, then copy its Client ID and Client Secret below.

  1. Open api.slack.com/apps and choose Create New App → From a manifest.
  2. Pick the Slack workspace, paste the manifest, and create the app.
  3. Open Basic Information and copy the Client ID and Client Secret.
