`input_contract.sh` regenerates `vectors/bot-input-contract.json` from the
pinned Rails image. `--check` requires identical regenerated bytes. The Ruby
script applies the controller's strong parameters before reading model casts
and validation errors, in UTC and America/New_York for credential expiry.

The corpus contains 81 cap, 21 icon and 42 expiry records. These are reference
facts, not passing Rust mutation counts. WS11 owns User icon normalization,
validation and writes, Agent raw-cap validation, and agent secret rotation.
The UI must pass those raw inputs through the corresponding domain seams.

Examples that the typed AgentChanges seam cannot currently represent:

- `" 12 "` and `"12.5"` cast to 12 but fail with `must be an integer`.
- `"12x"` casts to 12 but fails with `is not a number`.
- `true` casts to 1 but fails with `is not a number`.
- Arrays and hashes are dropped by the scalar strong-parameter filter.

Expiry number/true inputs remain uncast non-time model values in Rails. The
corpus records their types; a Timestamp-only Rust seam cannot represent them.
The selected date/string HTTP assertions do not establish parity for these
values, Rails multiparameter assignment, or the whole Date._parse grammar.
